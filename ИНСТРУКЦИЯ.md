# Запуск бота на Render Free

Что изменено по сравнению с обычной версией:
- **База не пропадает.** На бесплатном Render файлы стираются при каждом перезапуске, поэтому бот каждые 2 минуты сохраняет базу файлом в твой чат с ботом (аккаунт админа) и закрепляет это сообщение. При старте он восстанавливает базу из закреплённого файла. **Не открепляй и не удаляй это сообщение.**
- **Бот не засыпает.** Он сам пингует свой адрес каждые 10 минут.
- **Экономия памяти.** Chromium закрывается через 3 минуты после проверки (на Render всего 512 МБ).
- Новая админ-команда: отправить боту файл `.sqlite3` с подписью `/restore` — бот заменит базу этим файлом.

---

## 1. Залить файлы на GitHub

Репозиторий `kv9266855-sketch/edrsr-telegram-bot` сейчас пустой. Он **публичный**, поэтому заливай только содержимое этой папки: здесь нет ни токена, ни базы.

1. Открой https://github.com/kv9266855-sketch/edrsr-telegram-bot/upload/main
2. Перетащи в окно **содержимое** папки `edrsr_bot_render`: папку `app`, `Dockerfile`, `requirements.txt`, `.env.example`, `.gitignore`, `.dockerignore`. Этот файл с инструкцией можно не заливать.
3. Внизу нажми **Commit changes**.

⚠️ Никогда не заливай туда `.env` с токеном и папку `data`.

## 2. Остановить старого бота

Выключи бота на justrunmy (и на ПК, если запущен). Если тот же токен работает в двух местах, Telegram выдаёт ошибку `Conflict`.

## 3. Создать сервис в Render

1. https://dashboard.render.com/web/new → выбери `edrsr-telegram-bot`.
2. **Language**: `Docker`.
3. **Region**: `Frankfurt (EU Central)`.
4. **Instance Type**: **Free**.
5. **Environment Variables** → *Add Environment Variable*:
   - `BOT_TOKEN` = токен от @BotFather
6. **Advanced** → **Health Check Path**: `/health`
7. **Deploy Web Service**. Первая сборка идёт 5–10 минут.

В логах (вкладка **Logs**) должно появиться `Health server listening` и `Start polling`.

## 4. Перенести старую базу (пользователи, ключи)

При первом запуске база пустая. Чтобы вернуть пользователей и ключи:
1. Возьми файл базы `edrsr.sqlite3`: самую свежую версию с justrunmy, если её можно скачать, или ту, что лежит в `edrsr_bot_oracle\data\`.
2. С **аккаунта админа** отправь этот файл боту как документ и в подписи напиши `/restore`.
3. Бот ответит «Базу успішно відновлено з файлу».

## Если что-то не так

- **`Conflict: terminated by other getUpdates request`** — где-то ещё запущен этот же бот, останови его.
- **Сервис перезапускается, в логах `Out of memory`** — Chromium не влез в 512 МБ. Напиши мне, ужмём ещё.
- **`Не вдалося запустити браузер`** — пришли мне логи.
- **ЄДРСР: captcha / access denied** — реестр не пускает IP Render. Бот это не обходит, запишет ошибку и попробует в следующий раз.
- На Free-тарифе даётся 750 часов в месяц: на одного бота 24/7 хватает, но второй бесплатный сервис уже не влезет.
